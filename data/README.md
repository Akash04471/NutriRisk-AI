# NutriRisk AI Dataset Documentation

## Dataset Citation
* **Dataset Name:** Estimation of Obesity Levels Based on Eating Habits and Physical Condition
* **Original Authors:** Fabio Mendoza Palechor and Alexis de la Hoz Manotas
* **Publication:** *Data in Brief*, Volume 25, 2019, 104344
* **Repository:** UCI Machine Learning Repository (Dataset ID: 544)
* **URL:** [https://archive.ics.uci.edu/dataset/544/estimation+of+obesity+levels+based+on+eating+habits+and+physical+condition](https://archive.ics.uci.edu/dataset/544/estimation+of+obesity+levels+based+on+eating+habits+and+physical+condition)
* **License:** Creative Commons Attribution 4.0 International (CC BY 4.0)

## Dataset Directory Structure
* `data/raw/ObesityDataSet_raw_and_data_sinthetic.csv`: Original raw dataset downloaded from UCI.
* `data/processed/X_test.csv`: Untouched test set features (15% split).
* `data/processed/y_test.csv`: Untouched test set target labels.
* `data/processed/model_comparison_metrics.csv`: Untouched test set performance metrics table across all models.
